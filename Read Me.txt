This is my third complete Python project. It's an image analyser where the user uploads any image, then an AI analyses the image and the programme displays the selected image along with its description. 

I hope that you enjoy it!

Features: Image selection, AI-generated descriptions, loading feedback and error handling.

Technologies: Python, CustomTkinter, Pillow and the Gemini API.

How to set up: Download project, run: pip install -r requirements.txt, create a file called ".env" where you have a variable: API_Key = ... (insert your API key insetad of '...').

Then, run the program on Python - and enjoy!
